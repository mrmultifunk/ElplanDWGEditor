# Artikelbrowser 2.0 — 0.59.29

## Formål
Gøre den globale artikeldatabase hurtig at navigere uden at skjule producentens originale data.

## Arbejdsvisninger
- Alle artikler
- Favoritter
- Senest anvendte
- Brugt i projekt
- Kræver datakontrol

## Facetter
Fabrikat, standardkategori, type, produktfamilie, produktvariant, modul, farve, diameter, CCT og IP er kaskaderende. Hver dropdown viser antal mulige artikler under det aktuelle filter-scope.

## Søgning
Artikelnummer/EAN/EL-nr. vægtes højest. Beskrivelse og semantiske produktfelter vægtes derefter. Favorit, projektbrug og recency kan kun flytte relevante artikler op; de kan ikke gøre en ikke-matchende artikel synlig.

## Varianter og styklister
Previewet kan gå direkte til forrige/næste medlem i samme variantgruppe og viser navnene på globale styklister, hvor artiklen anvendes.
