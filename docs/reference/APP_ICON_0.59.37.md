# 0.59.37 – Programikon

Programmet har nu et egentligt app-ikon. Ikonet ligger i `assets/app_icon.png`
og `assets/app_icon.ico` og loeses ved runtime som baade applikations- og
vinduesikon. På Windows registreres der desuden et AppUserModelID, så
proceslinje/taskbar bruger det rigtige ikon i stedet for Pythons standardikon.
