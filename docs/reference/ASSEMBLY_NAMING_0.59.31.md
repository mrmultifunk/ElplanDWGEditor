# Navneassistent til styklister — 0.59.31

## Formål

Navneassistenten hjælper med ensartede montagenavne uden at låse brugeren til en automatisk navnestandard.

## Navnedele

1. Udførelse, fx `2×1M` eller `1½M`
2. System / serie, fx `FUGA AIR`, `FUGA SLIM`, `FUGA SOFT` eller `Wiser`
3. Type, fx `Stikkontakt`, `Afbryder`, `Kombiafbryder` eller `Lampeudtag`
4. Farve, fx `Hvid`, `Koksgrå` eller `Sort`
5. Ekstra tekst, fx `forfra` eller en projektspecifik betegnelse

Eksempel: `2×1M FUGA SLIM Stikkontakt Koksgrå forfra`.

## Manuel kontrol

Alle dropdowns er redigerbare. Assistenten skriver først til styklisteeditorens navnefelt, når brugeren vælger **Brug navn**. Navnefeltet forbliver derefter et almindeligt frit tekstfelt.

## Forslag fra montage

**Udfyld fra montage** kan foreslå værdier fra eksisterende navn, kategori/variant og artikelmetadata. Forslagene er konservative og påvirker ingen semantiske felter, BOM-data eller artikelbindinger.
