# Hover-overblik 0.50.13

## Lampested / PL-dåse

Efter 0,5 sekunds hover vises en lille, ikke-interaktiv popup med den fysiske kabelindføring. Den viser brugte indføringer 1-6, kabel-ID/mærkning, kabelspecifikation, kabelbenets side, fysisk PL-orientering, ledige indføringer og evt. kabelben som endnu ikke er placeret.

Lederfordelingen vises bevidst ikke i denne popup.

## Artikler og styklister

Symbolforekomster med artikel- eller styklistebinding viser en kompakt BOM-status ved hover. Kabler viser tilsvarende deres konkrete kabelartikel. Forekomster uden artikeldata får ingen ekstra popup, så plantegningen ikke bliver visuelt støjende.

## Datamodel

Ingen nye projektfelter.
