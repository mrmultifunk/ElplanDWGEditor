# PL-dåse 0.50.11 – fysisk orientering og montagerapport

## Fysisk orientering

PL-dåsen kan vælges i fire fysiske orienteringer relativt til plantegningens top:

- **0°** – indføring 1-2-3 vender mod plantegningens top.
- **90°** – indføring 1-2-3 vender mod højre.
- **180°** – indføring 1-2-3 vender mod bunden.
- **270°** – indføring 1-2-3 vender mod venstre.

Visningen er tænkt som set fra rummet/mod montagesiden. Portnumrene roterer med den fysiske dåse; eksisterende kabelben bliver på deres portnummer og remappes ikke.

## Udskriftsvenlig PL-dåserapport

**Værktøjer → PL-dåserapport…** eksporterer en A4-PDF med PL-montagekort. Hvert kort indeholder:

- PL-identifikation og lampeudtagstype
- fysisk orientering og reference til plantegningens top
- grafisk PL-dåse med port 1-6
- kabel-ID, kabeltype og kabelben pr. indføring
- Wago-samlinger og om de går videre til udtaget eller kun er sløjfer
- montagekontrol med fejl/advarsler

Rapporten er lavet som montagedokument og kræver ikke CAD-baggrunden.
