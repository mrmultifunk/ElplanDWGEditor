# PL-lederfordeling 0.50.4

Målet i 0.50.4 er at gøre lederforløbene endnu mere læsbare i PL-loftdåse-dialogen.

## Ændringer

- Lederne går nu **længere lodret ud fra kabelindføringen**, før de bøjer mod klemmerne. Det giver mere ro og gør det lettere at følge lederne visuelt.
- Parkeringsfelterne for **Reserve**, **Ikke tilsluttet** og **Frigør / ikke fordelt** er flyttet højere op i dåsen, så de ikke ligger visuelt bag de nederste ledergreb.
- **Ikke fordelte ledere** føres nu direkte til feltet **Frigør / ikke fordelt** i stedet for at ende som små frie spørgsmålstegns-ender.
- Standardfarven for **brun leder** er lysnet til `#a87943`, så den tydeligere aflæses som brun.

## Datamodel

Ingen nye felter. `pl_box_entries`, `pl_box_wiring` og `lamp_outlet_type` er uændrede.
