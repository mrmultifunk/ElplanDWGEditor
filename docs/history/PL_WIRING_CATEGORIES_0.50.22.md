# PL lederfordeling – kabelkategori 0.50.22

I fanen **Lederfordeling** viser hvert fysisk kabelkort nu den tilknyttede kabelkategori direkte under kabel-ID'et. Kategorien består af en kort prøve af kategoriens konfigurerede farve og kontur samt kategorinavnet. Kabeltype og kabelben vises i rækken nedenunder.

Visningen anvender projektets eksisterende `cable_categories` og ændrer ikke PL-data eller kabeldata.
